- PA4 data flow: immutable source buffer -> streaming `PPTokenizer` callbacks -> current logical-line preprocessing tokens -> macro/directive/include engine -> typed PA2 posttoken consumer. Dump output is an adapter, not phase transport. Includes share translation-unit state; each primary source resets macros, conditionals, once-state and counter. ## Completed behavior groups and remaining boundary

- **PA3 tokenization/evaluation throughput (repaired prerequisite).** Owner/data flow: `PPTokenizer::scan_operator` -> compact operator callback -> `ControlExpression::Parser` -> value output. The old operator scanner constructed/probed the entire punctuation candidate list for each punctuation token; it now dispatches to a maximal-munch-ordered bounded first-character group. Parser comparisons use the already-classified `OperatorKind`, not repeated spelling conversion. Work per input token is bounded; end-to-end cost tracks bytes/tokens/output. Validated against the full PA3 suite and the exact stress fixture, byte-identically.
- **PA4 macro replacement and directives.** Owner: `dev/src/preprocess/Preprocessor.cpp`; flow `PPTokenizer` -> typed tokens/macro expansion, directive/conditional/include state -> typed posttoken callbacks. Definitions/redefinition checks, arguments, stringize/paste/placemarkers, rescanning/recursion suppression, conditionals, includes, builtins, locations, pragmas and independent source reset remain covered by all macro/directive fixtures (105/105).
- **PA4 phase-5/7 integration.** Owner: `PostTokenPipeline.cpp` and `run_preprocessor_files`; token/literal facts flow directly to the reusable typed consumer. No serialized-token roundtrip was introduced. Later parser integration must preserve callback lifetime and source location facts.
- No current-stage implementation defect is known after the fixes and required checks. Further implementation work has no related failing behavior to target; stopping boundary is the passed full current-stage contract, with independent architecture/reference audit questions listed below. They are not waived or misreported as unfinished implementation.
